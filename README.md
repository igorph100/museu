# Sistema de arte de museu

Sistema de vendas e apresentação de obras de arte.
Realiza a venda de ingressos e grava o código do ingresso em um arquivo csv.

Apresenta informações em loop sobre as obras de arte selecionadas e ao final da apresentação coleta um feedback sobre a apresentação e salva o feedback em um arquivo csv

## Como compilar
Abra o arquivo .cbp no Code::Blocks e clique em Build and Run (F9).
